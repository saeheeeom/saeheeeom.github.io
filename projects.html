Multimodal behavioral monitoring for mental health

Ongoing

Georgia Tech Sonification Lab, with Prof. Bruce Walker

An agent that holds short daily check-in conversations and passively picks up facial and speech signals. The signals feed a multimodal stress-prediction model and a dashboard that tracks each person against their own baseline over time.

Hybrid vector search with query routing

2025

Georgia Tech, Database Systems (team project)

FAISS (IVF-PQ) vector search combined with SQLite metadata filters over 150K Wikipedia articles, feeding a RAG pipeline. Adaptive filter-first and search-first strategies cut latency 3–30×, and a small logistic-regression router picks the strategy per query (~96% F1).

GuardianDream: protecting faces from diffusion fine-tuning

2024

SNU MIPA Lab

Adds imperceptible noise to personal photos so that DreamBooth fine-tuning on them fails to reproduce the person's identity. Compared background-only and full-image perturbation, evaluated with FDFR, ISM, and SER-FIQ.
